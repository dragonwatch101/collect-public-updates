# Yo-kai Watch COLLECT

APK Android du projet de fan Yo-kai Watch COLLECT, non officiel et non commercial.

[Télécharger la dernière version](https://github.com/dragonwatch101/collect-public-updates/releases/latest)

Téléchargez le fichier `.apk` dans les pièces jointes de la version. Installez-le par-dessus la version précédente pour conserver votre collection. Android peut demander d'autoriser l'installation depuis votre navigateur. Ne désinstallez pas l'application pour la mettre à jour.

Ce dépôt contient uniquement les versions Android et leurs nouveautés. Le code source et les fichiers privés du créateur ne sont pas publiés.
